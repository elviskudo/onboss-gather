# Audit scope produksi

Tujuan tetap mengacu pada PRD Hallstatt Social 3D yang dilampirkan pengguna. Tabel ini membedakan implementasi lokal, bukti pengujian, dan syarat rilis yang belum terpenuhi. Preview statis bukan bukti bahwa layanan realtime sudah tersedia di produksi.

| Kebutuhan                                               | Bukti otoritatif saat ini                                                                   | Status dan pekerjaan tersisa                                                                                                              |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| Desa low-poly, avatar, kamera, collision, desktop/touch | `src/World.tsx`, `tests/app.spec.ts`, screenshot desktop/mobile                             | Masjid sudah menggantikan landmark sebelumnya; screenshot desktop/mobile sudah diperiksa. Perangkat nyata masih perlu diuji.              |
| Nama/avatar dan ID sesi                                 | Admission Worker dan event `welcome`; uji dua peserta                                       | Tersedia untuk sesi anonim. Kepemilikan akun/host permanen belum ada.                                                                     |
| Presence dan posisi realtime                            | Durable Object, WebSocket, uji protokol 20 koneksi                                          | Smoke test tersedia; bukan benchmark 20 pengguna dengan render/media.                                                                     |
| Proximity audio, mute, meeting bebas posisi, kamera     | `src/useMedia.ts`, `src/mediaPolicy.ts`, uji WebRTC perangkat sintetis                      | P2P lokal berfungsi; provider media terkelola sesuai PRD belum diintegrasikan.                                                            |
| Batas stream dan audio-only                             | Sender memilih paling banyak tiga video remote untuk tiap penerima; uji kebijakan 20 kamera | Aturan seleksi diuji; bandwidth, upstream fanout, perangkat fisik dan SFU belum divalidasi.                                               |
| Lock meeting dan kick oleh host                         | Otorisasi pada server, uji browser/protokol                                                 | Tersedia untuk peran sesi; belum identitas host permanen atau ban akun.                                                                   |
| Chat dan undangan                                       | Riwayat 60 pesan dalam storage Durable Object; shared-link                                  | Tersedia untuk pilot anonim. Token admission, proteksi abuse lintas sesi dan retensi produk masih diperlukan.                             |
| Reconnecting dan retry                                  | `src/useRoom.ts`, heartbeat native Worker, `tests/connection.spec.ts`                       | Perubahan baru mencakup timeout admission, pemulihan online/offline dan sinkronisasi spawn; hasil pengujian dicatat di `verification.md`. |
| PWA dan adaptasi mobile/tablet                          | Manifest, service worker, viewport test, mode grafis ringan                                 | Shell offline penuh, installability lintas browser, touch/mic/camera pada perangkat nyata belum dibuktikan.                               |
| Bevy/Rust WASM dan workers-rs                           | Belum ada crate Rust/Bevy                                                                   | Implementasi sekarang TypeScript/Three.js; belum memenuhi default arsitektur Rust pada PRD.                                               |
| D1 users/spaces/meetings/settings dan migrasi           | Belum ada schema/migrasi D1                                                                 | State sesi memakai Durable Object. Model produk permanen sesuai PRD belum diimplementasikan.                                              |
| R2 untuk model/peta                                     | Geometri saat ini dibuat kode dan dibundel                                                  | Tidak ada model eksternal; jalur aset R2 belum diimplementasikan.                                                                         |
| Media terkelola RealtimeKit dan token server            | Native WebRTC saat ini                                                                      | Belum ada integrasi provider/token issuer; konfigurasi akun dan implementasi masih diperlukan.                                            |
| Deployment penuh, monitoring, biaya dan rollback        | `wrangler.jsonc`, workflow CI, observability config; preview Sites privat                   | Backend penuh belum dideploy. Autentikasi Cloudflare, secrets media, alert, anggaran, rollback dan verifikasi domain final belum lengkap. |
| Lisensi aset                                            | Geometri orisinal, `public/THIRD_PARTY_NOTICES.txt`                                         | Notice pihak ketiga disertakan; tidak memakai aset Gather.town.                                                                           |

Goal belum dapat dinyatakan selesai sampai bukti yang sesuai tersedia untuk setiap persyaratan, termasuk arsitektur yang diminta dan layanan produksi. Pengujian lokal yang lulus tidak menggantikan gate produksi atau mengubah scope menjadi preview saja.
